# Zombie Panic in Wonderland

A low-poly 3D browser game made with three.js: zombies have risen in Wonderland, and you hold the
ruined road against wave after wave of them, then their boss.

Play it: https://wonderland.cocode.dk/

## Controls

A / D or ← / → move · mouse aims · hold the left button to shoot · Space dodges · Esc pauses · 1 2 3 or wheel: weapons · M sound

## Tests

    node --test

## Play locally

Serve the repository folder with any static web server and open the page it prints, for example:

    python3 -m http.server

## How it was built

Built by graph-loop's lean loop (https://github.com/cocodedk/graph-loop) from the specs in
`docs/lean/`. The owner turns Pages on; merging to main then publishes the game.
